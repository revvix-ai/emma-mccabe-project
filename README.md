# Emma McCabe - The 1% Edge

A premium, high-conversion personal brand website designed for Emma McCabe, a business and mindset coach who helps coaches, consultants, and service-based entrepreneurs build profitable businesses and create more freedom.

This project delivers a luxury editorial web experience that stands out from generic coaching websites. It embodies ambition, high performance, and freedom, utilizing a modern, cinematic visual language.

## 👤 Client Information
**Client:** Emma McCabe  
**Role:** Business & Mindset Coach • Founder • Entrepreneur  
**Target Audience:** Coaches, consultants, and service-based founders ready to scale and enter "The 1%".  
**Goal:** To provide a digital home that reflects a successful international personal brand, prioritizing visual impact, strategic storytelling, and conversion.

## 🎨 Theme & Visual Direction
The design language is inspired by high fashion magazines, creative portfolios, and modern art direction.

- **Vibe:** Luxury editorial, bold, confident, cinematic, modern, and aspirational.
- **Color Palette:** 
  - 🖤 **Primary:** Black & Charcoal
  - 🤍 **Backgrounds:** Off-white & Warm Cream
  - 🟩 **Accents:** Acid Green (used sparingly for highlights, important numbers, and CTAs)
- **Typography:** Oversized, bold, and expensive-feeling editorial fonts. Asymmetric layouts and vertical typography.
- **Imagery:** Cinematic photography overlapping with text, breaking out of traditional rectangular grids.
- **Layouts:** Minimal UI elements, strong whitespace, magazine-inspired grids, and large section numbers (01, 02, 03...).

## 💻 Tech Stack
This project is built using a modern, high-performance React ecosystem:

- **Core:** [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Framework & Routing:** [TanStack Start](https://tanstack.com/start/latest) & [TanStack Router](https://tanstack.com/router/latest)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components:** 
  - [Radix UI](https://www.radix-ui.com/) (Accessible headless components)
  - [Lucide React](https://lucide.dev/) (Icons)
  - [Embla Carousel](https://www.embla-carousel.com/) & [Vaul](https://vaul.emilkowal.ski/) (Drawers)
- **Forms & Validation:** [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Data Fetching:** [TanStack Query](https://tanstack.com/query/latest)
- **Build Tool:** [Vite](https://vitejs.dev/)

## 🚀 Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed on your machine. We recommend using `nvm` to manage your Node versions.

1. **Clone the repository**
   ```bash
   git clone https://github.com/revvix-ai/emma-mccabe-project.git
   cd emma-mccabe-project
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🛠 Scripts
- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Locally preview the production build.
- `npm run lint`: Runs ESLint to catch code issues.
- `npm run format`: Formats code using Prettier.
